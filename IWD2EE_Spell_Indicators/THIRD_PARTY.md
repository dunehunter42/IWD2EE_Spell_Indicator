# Third-party installer

`setup-IWD2EE_Spell_Indicators.exe` is an unchanged copy of WeiDU 24900, renamed for this mod. The WeiDU license is included in `WeiDU-COPYING.txt`.

Upstream source and releases: https://github.com/WeiDUorg/weidu

Version 249 source: https://github.com/WeiDUorg/weidu/tree/v249

This package includes no game executable, BG2 artwork or copied game resource assets. The preview shapes are drawn at runtime.
